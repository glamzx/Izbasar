# Персональный сайт Избасара Мамырова (Personal Brand Website)

Официальный landing page сайт Избасара Мамырова — дипломированного психолога, специалиста по КПТ (когнитивно-поведенческой терапии) и ICF-коуча.

## 🚀 Особенности и Стек
- **Дизайн**: Modern Editorial Warm Cream background (`#F9F8F3`) с иконками, зелеными акцентами (`#2D6A4F`, `#52B788`) и SVG-графикой в стиле референса №5.
- **Интерактивный видеоплеер**: Встроенный всплывающий плеер для YouTube-ролика («Как изменить свою жизнь через изменение состояния?»).
- **Связь через WhatsApp**: Все кнопки записи и получения книги ведут прямо на официальный номер WhatsApp (`+7 (700) 338-99-79`) с готовым текстом обращения.
- **Технологии**: Pure HTML5, Vanilla CSS3 (Design Tokens), Vanilla JS (Lucide Icons). Zero dependencies, молниеносная загрузка и идеальный SEO-показатель.

## 📸 Как заменить фотографии на реальные
1. Замените файлы в папке `assets/`:
   - `assets/hero_portrait.jpg` — Главное портретное фото Избасара для Hero-секции.
   - `assets/about_portrait.jpg` — Вторичное фото для блока "Обо мне".
   - `assets/ebook_cover.jpg` — Изображение обложки бесплатной книги.
2. Имена файлов можно оставить теми же, либо изменить пути в `index.html`.

## 🌐 Как опубликовать сайт на GitHub Pages
1. Отправьте изменения в свой GitHub репозиторий `https://github.com/glamzx/Izbasar`:
   ```bash
   git add .
   git commit -m "Add Izbasar personal website"
   git push origin main
   ```
2. В GitHub перейдите в **Settings** -> **Pages**.
3. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
4. Нажмите **Save**. Через 1-2 минуты ваш сайт будет доступен в сети!
